# 19 — Economy (presentation)

How money and progress *appear* in brand — not smart-contract specs.

| Element | Presentation |
|---------|----------------|
| **Bitcoin** | ₿ + sats; gold coin pixel icon |
| **Arcade credits** | Optional meta layer; always convertible narrative to sats |
| **Tickets** | Prize counter aesthetic |
| **XP / levels** | Progress bars; never outshine BTC balance |
| **Season pass** | Marquee seasonal; cosmetic + entry perks |
| **Rewards** | Clear sats/BTC amounts; no hidden rake language in UI |

Honesty: show cost to play before insert. Cash out path visible.
