# 12 — Motion

## Principles

- Snappy arcade timing over cinematic ease  
- Pixel animations = discrete frames (ch. 07)  
- UI motion = short (150–280ms), ease-out  

## Signature moments

| Moment | Direction |
|--------|-----------|
| Logo intro | Pixel reveal or CRT power-on |
| CRT startup | Phosphor bloom → face on |
| Cabinet boot | Marquee flicker → attract mode |
| Insert coin | Coin drop arc + SFX |
| Transitions | Hard wipe / scanline / brief glitch |
| Win | Coin particles, confetti, hyped Chip |
| Lose | Short dim + retry CTA |
| Jackpot | Full-screen gold storm (sparingly) |

## Glitch & scanlines

- Overlay scanlines ≤ 8% opacity  
- Glitch: 1–3 frame RGB split max; stay on-brand colors  

## Don't

- Long luxury fades  
- Motion that blurs pixel sprites
