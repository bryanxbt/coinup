# 04 — Visual Identity / Logo Suite

**Source:** Brand Book v1.0 — panels 00 & 04

## Primary logo

**COINUP ARCADE** wordmark in brand pixel display:

- `COINUP` large, multi-stop arcade colors (gold → orange → pink energy)  
- `ARCADE` smaller beneath or integrated  
- Optional Chip head + hat above mark for full stack logo  

## Suite

| Asset | Description |
|-------|-------------|
| **Primary logo** | Full COINUP ARCADE + optional Chip hat stack |
| **Wordmark** | COINUP ARCADE horizontal |
| **Icon** | Pixel **C** in circle (gold coin style) |
| **App / favicon** | C icon or Chip face CRT |
| **Badge** | Small Chip head lockup |

## Safe area & size

- Clear space ≥ height of the **C** counter  
- Min digital wordmark ~96px wide  
- Icon min 16×16 (from 32×32 master)  

## Incorrect usage (see also panel 16)

- Don't stretch the logo  
- Don't recolor outside brand palette  
- Don't add foreign brand logos  
- Don't blur, glow-smear, or gradient-mesh the **pixel** C  
- Don't be boring  

## Patterns (panel 07)

Reusable textures:

| Pattern | Use |
|---------|-----|
| **Arcade** | Diamond plate / metal floor energy |
| **Coin** | Repeating C coins |
| **Energy** | Chevron / lightning repeat |
| **Grid** | Cabinet HUD / graph paper |

Patterns stay **pixel-aligned** when used behind UI; opacity low (8–20%).
