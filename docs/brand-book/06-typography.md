# 06 — Typography

**Source:** Brand Book v1.0 — panel 06

## Stack

| Role | Font | Use |
|------|------|-----|
| **Display / Headlines** | **Coinup Pixel** (brand pixel face) | Logos adjacent titles, marquee lines, big game names |
| **Subhead / UI** | **Press Start 2P** | Buttons labels energy, “PRESS START”, micro arcade chrome |
| **Body** | **Inter** | Readable paragraphs, settings, legal-adjacent |

Web fallbacks until full font files ship:

- Display → `Press Start 2P` or `ui-monospace` with pixel CSS where needed  
- Body → `Inter`, system-ui  

## Specimens

**Display:**  
`COINUP PIXE` · A–Z 0–9 symbols  

**Subhead:**  
`PRESS START 2P` · UI strings in all-caps when arcade-voiced  

**Body:**  
Inter regular/medium for sentences. Never set long paragraphs in Press Start 2P.

## Hierarchy

| Level | Font | Notes |
|-------|------|-------|
| Marquee H1 | Coinup Pixel / display | Gold–pink gradient OK on *vector type only*, not on pixel sprites |
| Section H2 | Press Start 2P or bold Inter | Pink section labels on brand board |
| Card title | Inter semibold or display small | |
| Body | Inter 15–16px | |
| Micro HUD | Press Start 2P 8–10px | Careful: limited readability |

## Numbers & scores

- In-cabinet scores: pixel numerals (Pixel System)  
- Lobby balances: Inter or mono tabular (`0.045678 BTC`)  
- Prefer **sats** for small amounts; BTC when board shows prestige  

## Don't

- Body copy in Press Start 2P  
- Random third display fonts  
- Fake bold via stretch
