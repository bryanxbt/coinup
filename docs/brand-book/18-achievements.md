# 18 — Achievements

## Badge system

Pixel icons at 32 / 64. Rarity frames:

| Tier | Frame feel | Color cue |
|------|------------|-----------|
| Bronze | Soft copper | Warm steel |
| Silver | Cool metal | Silver |
| Gold | Coin gold | `#FCC76E` |
| Diamond | Cyan ice | `#00D0FF` |
| Legendary | Pink/gold shift | `#FF4EC7` + gold |

## Rules

- Icon readable at 32  
- Name + one-line description  
- No pay-to-unlock cosmetics that imply unfair scores
