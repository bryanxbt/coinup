# 16 — Marketing Templates

Standardized canvases (build in Figma later; rules now).

| Channel | Size guide | Must include |
|---------|------------|--------------|
| YouTube thumb | 1280×720 | Face/cabinet + ≤ 4 words |
| TikTok/Reels | 1080×1920 | Safe top/bottom for UI |
| Instagram post | 1080×1080 | Brand mark corner |
| X header | 1500×500 | Chip or cabinets; no tiny type |
| Discord banner | Per server | Mission micro line |
| Email header | 600 wide | Logo + one CTA |
| Pitch deck | 16:9 | Board colors; Inter body |
| Wallpaper | 4K / phone | Pixel pattern + mark |
| Banner ads | IAB sizes | INSERT COIN CTA |

Always legal/line: not financial advice if required by counsel; brand voice stays arcade.
