# 10 — Cabinet System

Every game is a **cabinet**, not a faceless app tile.

## Anatomy

| Part | Spec |
|------|------|
| **Marquee** | Game title in display/pixel type, game accent color |
| **Bezel / screen** | Dark; gameplay or attract mode |
| **Side art** | Character/logo, C badge, lore stickers |
| **Control panel** | Joystick + buttons; pixel-readable |
| **Coin door** | Gold C / insert slot |
| **Instructions** | Short: “DROP THE COIN. LAND IN A HIGH MULTIPLIER SLOT!” |
| **Lighting** | Edge neon in game accent |

## Board example — Coin Drop

- Marquee: **COIN DROP**  
- Body: varsity blue cabinet  
- Side: C badge + art  
- Copy: *Drop the coin. Land in a high multiplier slot!*
