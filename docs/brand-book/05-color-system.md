## Rules

1. **Product UI** uses this system freely for chrome, buttons, type color.  
2. **Pixel art** must still index the **Pixel System 32** (ch. 07), which maps onto these brand hues.  
3. Default stage is **void** (`#000012`) — CoinUp is a night arcade.  
4. CTAs: orange or gold fill + dark/void label, or blue fill + white label.  
5. Never lead a screen with pure white full-bleed (except print/light merch).  

## Accessibility

- Body text on void: white or gold at large sizes; check contrast for small pink-on-void  
- Don't use pink alone for errors — pair with red + icon  
- Balance and BTC amounts: white/gold on dark panels  

## Photography grade

Photos may grade toward **retro · vibrant · neon · authentic** (ch. 13 board panel) — deep blues, neon pink/orange rim light, coin gold speculars.
