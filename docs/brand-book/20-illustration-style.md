# 20 — Illustration Style

| Style | When |
|-------|------|
| **Pixel** | Default universe (Pixel System) |
| **CRT** | Chip face, monitors, lore UI |
| **Cabinet** | ¾ perspective cabinets as on board |
| **Sticker** | Social, merch die-cuts |
| **Neon photo composite** | Marketing only; grade to brand |
| **Comic** | Optional lore strips; Chip on-model |

Perspective for cabinets: slight ¾, readable controls. Lighting: neon rim + dark fill.
