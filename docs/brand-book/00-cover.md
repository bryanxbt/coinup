## How to use this book

CoinUp is a **living entertainment brand**: mascot, universe, games, merch, social, UI, pixel art, cabinets, overlays, events.

Target internal depth: **80–120 pages** when fully illustrated — comparable to Nintendo / LEGO / Discord / Riot / Supercell franchise bibles.
