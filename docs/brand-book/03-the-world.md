# 03 — The World of CoinUp

> This is something infrastructure brands don’t have: a **place** and a **cast**.

The World is canon. UI, social, merch, and events should feel like dispatches *from* the arcade — not bolted-on campaigns.

---

## The Arcade

### History

CoinUp Arcade begins as intention on empty ground: a digital floor that behaves like a real one — cabinets, manager, prizes, tournaments, closing time that never comes.

### The Dirt Lot (Day 1)

Visual anchor: Chip in varsity jacket, back to camera, blueprints on a folding table, excavator and skyline beyond, **C** lot sign. Polaroid label: **DAY 1**.

Use Day 1 for:

- Origin stories  
- Construction updates  
- “We’re still building” honesty  
- Hiring / contributor calls  

### Opening Day

First cabinets powered. First insert coin SFX. Chip’s badge scanned. Mission line goes up on the marquee.

### Expansion

New cabinets = new rooms on the floor plan. Seasons redecorate; they don’t demolish lore.

### Future

Physical pop-ups, tournament stages, merch drops, possibly real cabinets that mirror digital ones. Always the same world.

## Chip the Arcade Manager

| | |
|--|--|
| **Name** | Chip |
| **Title** | Arcade Manager |
| **Access** | ALL ACCESS |
| **Species** | CRT-head robot (pixel) |
| **Uniform** | Blue/gold varsity, COINUP ARCADE hat, sneakers |

### Origin

Chip arrived with the first blueprint tube. No one hired him in a corporate sense — he *assumed* the floor. The badge says MANAGER; the floor agrees.

### Personality

- Professional floor energy with glitch humor  
- Protective of fair play  
- Loves high scores more than hype threads  
- Sleeps in ERROR 404 mode  

### Expressions (CHIP.EXE)

| Key | Label | Use |
|-----|--------|-----|
| `thinking` | THINKING… | Load, consider, neutral |
| `hyped` | HYPED | Win, launch, insert |
| `determined` | DETERMINED | Match start, finals |
| `sleep` | ERROR 404: SLEEP | Offline, late night, empty |

Full turnaround & gear: **ch. 08**.

### Voice

Short. Arcade. Sometimes system-log funny.

**Says:**  
“Insert coin to continue.” · “You’re up.” · “Board’s watching.” · “1UP starts here.” · “All access. Don’t abuse it.”

**Never says:**  
“WAGMI.” · “This is not financial advice” as personality. · “Stake your LP.” · Slang that ages in six weeks. · Mean-spirited dunks on new players.

### Example tweets (voice samples)

> doors open. chip on duty. insert coin.  

> new cabinet on the truck. dirt still on the wheels. day 1 never ended.  

> high score ghost spotted on coin drop. prove it wrong.  

> ERROR 404: SLEEP — floor reopens with caffeine and sats.  

### Memes & reaction images

Chip faces as reaction pack: Thinking / Hyped / Determined / Sleep.  
Export rules: Pixel System sizes, nearest-neighbor only. See **ch. 15**.

### Animation rules (summary)

- Idle: soft phosphor blink, 2–3s  
- Celebrate: hyped face + jacket bounce, 8–12 frames  
- No motion blur; discrete frames only  
Detail: **ch. 07** + **ch. 12**

## World rules

1. The arcade is always *somewhere* — never pure void without floor language  
2. Chip is manager, not god-emperor; cast has agency  
3. New games arrive as **cabinets**, not random app icons only  
4. Bitcoin is diegetic (coins, slots, prizes)  
5. Day 1 remains visible in brand memory
